管理画面のファイルは用意できています。あと2か所の設定で、GitHubログインから編集・公開ができます。

  1. GitHubでOAuth Appを作成。Homepage URLを https://lovot.pages.dev、Authorization callback URLを https://lovot.pages.dev/api/callback にします。
  2. Cloudflare Pagesの「lovot」→ Settings → Variables and Secretsで、GITHUB_OAUTH_CLIENT_ID と GITHUB_OAUTH_CLIENT_SECRET を本番環境に設定。Secretは暗号化して保存し、同じデプロイを再実行してください。

秘密の値をチャットやGitHubのファイルへ書かないでください。設定後、このページを再読み込みします。

GitHubの認証は、このリポジトリに書き込み権限のあるアカウントで行ってください。
