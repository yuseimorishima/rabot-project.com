# ひみつのへや

写真館の検索欄で `ひみつのへや` または `秘密の部屋` と入力し、検索を実行すると `/playroom.html` を開きます。写真館には折りたたみ式のヒントがあります。通常のナビゲーションには載せず、検索エンジンには noindex を指定しています。これは遊びの入口であり、認証やアクセス制限ではありません。

なでる・遊ぶ・充電でごきげんや充電、なかよし度が変わります。40ポイントごとにレベルアップし、最大Lv.6です。充電が20未満だと遊べません。経過時間で充電とごきげんが少し減りますが、計算は最大4時間分で、なかよし度は減りません。実際のLOVOTの仕様を再現するゲームではありません。

状態は同じオリジンのブラウザの localStorage (`lovot-playroom-v1`) に保存します。端末間同期はありません。保存が利用できなくてもページ内で遊べ、保存不可の案内を表示します。名前の変更、確認付きリセットに対応しています。ゲームは静的ファイルだけで動き、管理者認証や外部サービスへの接続は不要です。

検証: `node --test tests/playroom.test.mjs` と `node tests/editor-auth.test.mjs`。開発サーバーは既存の Wrangler Pages 開発手順を使用します。公開サイトに反映するには、通常のコードレビュー・マージとCloudflare Pagesへのデプロイが必要です。

## おめかしガチャ

初回コイン6枚、なでると1枚、遊ぶと2枚。充電や充電不足で遊べなかった場合には増えません。ガチャは1回3枚で、重複時は1枚返却。コインの購入・課金機能はありません。全11着（初期のミルク1着、抽選10着）です。各服の確率は画面内で確認でき、ノーマル4着が各16%、レア2着が各8%、星空が4%、うさぎ・ねこが各6%、こぐまが4%です。天井や重複排除はありません。

クローゼットで入手済みの服を着せられます。服の色はフード・胴体・腕に、柄は胴体に反映されます。キャラクターはゲーム用のオリジナル3Dモデル（代替表示はCSS）で、公式の商品画像・公式3Dモデルではありません。既存の育成データは名前・なかよし度を維持して移行し、初期の服とコインを受け取れます。リセットは所持服・コインも削除します。


## 立体の部屋

`playroom-pet.js` が基本形状からキャラクターを組み立てます。フード・体・腕の色と柄、動物の耳としっぽが連動します。目線・まばたき、呼びかけへの接近、床のタップ先への移動、なでる・遊ぶ・充電の反応、後ろ姿を見る回転に対応しています。コインやなかよし度は移動・呼びかけだけでは増えません。

3DはWebGL2が使える場合に表示します。読み込み失敗・コンテキスト喪失時にはCSS表示とお世話ボタンへ戻します。動きを減らす設定では自動移動・まばたき・連続回転を止め、呼びかけや床タップでは即座に位置を変更、回転ボタンでは背面へ切り替えます。画面外・非表示タブでは描画せず、解像度倍率は1.75に制限しています。

Three.js 0.180.0 をローカル配信するため外部CDNへの通信は不要です。`assets/vendor/three-0.180.0.js` と `three-LICENSE.txt` を同梱。更新時はリポジトリ外の作業ディレクトリで `three@0.180.0` と `esbuild@0.25.12` をインストールし、`playroom-pet.js` が使う名前付きエクスポートを含むエントリを `--bundle --format=esm --minify --legal-comments=eof` でビルドしてください。通常の起動・デプロイでは再ビルド不要です。

3D・保存・CSS代替表示のブラウザ検証は、開発サーバーを起動したうえで `node --test tests/playroom-browser.test.mjs` を実行します。環境のPlaywrightと `/usr/bin/chromium` を使用します。別サーバーの場合は `PLAYROOM_TEST_URL` を指定してください。
