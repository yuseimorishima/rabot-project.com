# ひみつのへや

写真館の検索欄で `ひみつのへや` または `秘密の部屋` と入力し、検索を実行すると `/playroom.html` を開きます。写真館には折りたたみ式のヒントがあります。通常のナビゲーションには載せず、検索エンジンには noindex を指定しています。これは遊びの入口であり、認証やアクセス制限ではありません。

なでる・遊ぶ・充電でごきげんや充電、なかよし度が変わります。40ポイントごとにレベルアップし、最大Lv.6です。充電が20未満だと遊べません。経過時間で充電とごきげんが少し減りますが、計算は最大4時間分で、なかよし度は減りません。実際のLOVOTの仕様を再現するゲームではありません。

状態は同じオリジンのブラウザの localStorage (`lovot-playroom-v1`) に保存します。端末間同期はありません。保存が利用できなくてもページ内で遊べ、保存不可の案内を表示します。名前の変更、確認付きリセットに対応しています。ゲームは静的ファイルだけで動き、管理者認証や外部サービスへの接続は不要です。

検証: `node --test tests/playroom.test.mjs` と `node tests/editor-auth.test.mjs`。開発サーバーは既存の Wrangler Pages 開発手順を使用します。公開サイトに反映するには、通常のコードレビュー・マージとCloudflare Pagesへのデプロイが必要です。

## おめかしガチャ

初回コイン6枚、なでると1枚、遊ぶと2枚。充電や充電不足で遊べなかった場合には増えません。ガチャは1回3枚で、重複時は1枚返却。コインの購入・課金機能はありません。全11着（初期のミルク1着、抽選10着）です。各服の確率は画面内で確認でき、ノーマル4着が各16%、レア2着が各8%、星空が4%、うさぎ・ねこが各6%、こぐまが4%です。天井や重複排除はありません。

クローゼットで入手済みの服を着せられます。服の色はフード・胴体・腕に、柄は胴体に反映されます。キャラクターは参考写真から生成したゲーム用画像で、公式提供の画像ではありません。既存の育成データは名前・なかよし度を維持して移行し、初期の服とコインを受け取れます。リセットは所持服・コインも削除します。


## 本体の見た目の試作

公式サイトの参考スクリーンショットを参照して生成した透過画像 `assets/lovot-game-base.png` を表示します。公式から提供された商品画像ではありません。元画像は編集せず、ゲームの実行時に `playroom-sprite.js` が白い服のピクセルだけをCanvasで着色します。顔・目・タワー・車輪は色を保ちます。通常の起動に画像生成やビルドは不要です。

本体画像を浅い凹凸のある面に貼り、Canvas 2Dの三角形メッシュで向き・うなずき・腕の反応を描きます（`playroom-motion.js`）。正面付近の角度に限定する2.5D表現で、背面や360度回転には対応していません。着替え後の画像も同じ面に貼るため顔や服の柄を維持します。動物の耳はCSSの重ね合わせです。

呼びかけで手前へ寄り、床タップで左右・奥行き方向に移動、「いつもの場所へ」で戻ります。「動きを止める」で停止できます。24fpsを上限にし、画面外・非表示タブでは描画を止めます。動きを減らす設定では自動の揺れ・変形を止め、移動先へ即座に切り替えます。描画モジュールが読み込めなくても画像表示・お世話・着替えは続けられます。服を集める仕組みと既存の保存状態は引き継ぎます。

ブラウザ検証は開発サーバーを起動したうえで `node --test tests/playroom-browser.test.mjs` を実行します。環境のPlaywrightと `/usr/bin/chromium` を使用し、別サーバーの場合は `PLAYROOM_TEST_URL` を指定してください。
