# ひみつのへや

写真館の検索欄で `ひみつのへや` または `秘密の部屋` と入力し、検索を実行すると `/playroom.html` を開きます。写真館には折りたたみ式のヒントがあります。通常のナビゲーションには載せず、検索エンジンには noindex を指定しています。これは遊びの入口であり、認証やアクセス制限ではありません。

なでる・遊ぶ・充電でごきげんや充電、なかよし度が変わります。40ポイントごとにレベルアップし、最大Lv.6です。充電が20未満だと遊べません。経過時間で充電とごきげんが少し減りますが、計算は最大4時間分で、なかよし度は減りません。実際のLOVOTの仕様を再現するゲームではありません。

状態は同じオリジンのブラウザの localStorage (`lovot-playroom-v1`) に保存します。端末間同期はありません。保存が利用できなくてもページ内で遊べ、保存不可の案内を表示します。名前の変更、確認付きリセットに対応しています。ゲームは静的ファイルだけで動き、管理者認証や外部サービスへの接続は不要です。

検証: `node --test tests/playroom.test.mjs` と `node tests/editor-auth.test.mjs`。開発サーバーは既存の Wrangler Pages 開発手順を使用します。公開サイトに反映するには、通常のコードレビュー・マージとCloudflare Pagesへのデプロイが必要です。

## おめかしガチャ

初回コイン6枚、なでると1枚、遊ぶと2枚。充電や充電不足で遊べなかった場合には増えません。ガチャは1回3枚で、重複時は1枚返却。コインの購入・課金機能はありません。全8着（初期のミルク1着、抽選7着）です。各服の確率は画面内で確認でき、ノーマル4着が各20%、レア2着が各8%、スペシャル1着が4%です。天井や重複排除はありません。

クローゼットで入手済みの服を着せられます。服の色はフード・胴体・腕に、柄は胴体に反映されます。キャラクターはゲーム用のCSS表現で、公式の商品画像ではありません。既存の育成データは名前・なかよし度を維持して移行し、初期の服とコインを受け取れます。リセットは所持服・コインも削除します。
